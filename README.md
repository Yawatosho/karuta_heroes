# NDC KARUTA HEROES — UPGRADED EDITION

「知識を、連撃に。」

元のNDC Karuta Heroesのルール・バランス・キャラクター・素材を引き継ぎ、画面構成と演出、ゲームプログラムを新しく作り直した独立版です。

## 遊ぶ

**ローカルでは `offline.html` をダブルクリックしてください。** 素材・音声・分類データはすべてこのフォルダに同梱されています。インターネットも元の `NDC_Karuta_Heroes` フォルダも必要ありません。

HTTPサーバーで遊ぶ場合は、このフォルダで `python3 -m http.server 4176` を実行し、ブラウザで `http://localhost:4176` を開きます。サーバー版の入口は `index.html` です。

横画面では1366×768のステージを等比表示します。スマートフォンの縦画面では縦長の専用レイアウトに自動で切り替わり、札を3列に配置します。ノッチ・ホームバーの余白と画面回転にも対応しています。縦画面のプロローグ・対戦導入・勝利・エンディングには元ゲームの縦画面用素材45点を同梱して使用します。

## 操作

- 分類札：クリック／タップ。キーボードは上段 `1 2 3 4 5 6`、下段 `Q W E R T`。
- 必殺技：`SPACE` または `SPECIAL` ボタン。
- 一時停止：`ESC` または歯車ボタン。別タブに移動したときも自動停止します。
- 2人対戦：同じ端末でマウス、キーボードA、キーボードBを重複しないように選択。
- 設定：サウンド、音量、画面揺れ・エフェクト。OSの「視差効果を減らす」設定を初期値に反映します。

## 引き継いだルール

5人のプレイヤーと4人のCPU。11枚の場札・1ターン15秒・1ラウンド10ターン・2ラウンド先取。数字を2秒間隔で読み上げ、対応する分類名の札を取ります。お手つきはそのターンの解答権を失い、双方の誤答や時間切れではダメージが発生しません。

ダメージは14から始まり、コンボごとに4増加、基本上限34。探偵と格闘系司書は与・被ダメージとも1.2倍、リリーは0.8倍。SUPERゲージは早い正解ほど増加し、相手の正解でも少し増えます。ゲージはラウンド間で持ち越します。2人対戦は双方の体力100、能力補正・必殺技なしです。

EASYは体力120・1の位が0の分類のみ、NORMALは100、HARDは90。CPU速度・正答率、敵必殺技、プレイヤー5人の必殺技、格闘系司書の3連続正解K.O.も引き継いでいます。

## 新しい画面と演出

- OGPのイラスト内のタイトル文字を生かしたタイトル画面。縦横ともイラストを全画面に表示し、モード選択を下部に重ねて配置。大きなファイター選択は背景・メニューを維持した部分更新。
- 対称配置の体力バー、ダメージの残像、ラウンド獲得マーク、SUPERゲージ。
- 正解札の残像と相手の体力バーへ走る光、連撃に応じた火花と衝撃。決着の一撃は光を集中させ、K.O.の出現へつなげます。通常のターンでは残った札を表示したまま維持。
- 分類札は語句・単語の区切りで改行し、下位分類や括弧内の説明は一段小さく表示。長い分類名は札の実寸に合わせて調整し、通常のターンでは表示を維持します。
- 必殺技の間は、読み上げ・CPU・ターン時計をまとめて停止。専用SE（`sound/special.mp3`）を使用。9人の素材に合わせた色・装飾と、縦画面で顔が見える構図を使用します。
- 必殺技とK.O.ではBGMを下げ、SEの終了後に滑らかに戻します。数字の読み上げ中は必殺技SEの余韻を抑え、読み上げ音量を維持します。演出OFFでは動きを省いた表示になります。
- BGMは同じ再生要素を使い続け、スマートフォンのタップで再生許可を得てから曲を切り替えます。再生が止まった場合は次のタップで再開を試みます。数字の音声10本は最初の操作で事前読み込みします。
- 共通オープニングと個別ストーリー、ラウンド勝利、結果、5人の個別エンディング、クレジット。縦長のラウンド絵は全体表示、結果は画像内の文字とセリフ枠を使用。
- 初回練習、進行の自動保存、見た演出のギャラリー、25枚のクリア報酬アート、6曲のサウンドテスト。

保存はブラウザ内です。同じ端末・ブラウザ・保存領域に旧版のセーブが残っている場合、初回起動時にギャラリー（縦画面の開放状況を含む）・アートワーク・練習完了状態を新版へ一度だけ引き継ぎます。新版のセーブがまだない場合は、キャラクター・難易度・ステージ・プロローグ／エンディングの続きも引き継ぎます。新版のセーブがある場合は、そのストーリー進行と設定を優先し、開放状況を統合します。

旧版の保存データは変更・削除しません。旧版フォルダへの参照も不要です。旧版・新版がともに `https://yawatosho.github.io/` 配下にある場合、URLのフォルダ名が異なっても同じ保存領域を使えます。localhost・別ドメイン・別ブラウザ・ダブルクリックの別ファイルなど、保存領域が異なる場合は自動移行できません。ブラウザのサイトデータを消すと進行とギャラリーも消えます。

## 構成とメンテナンス

ゲーム本体は外部ライブラリ・CDN・外部分類データ取得・ビルドツールに依存しません。公開版のアクセス解析のみ、Google Analyticsのタグを読み込みます。タグが読み込めない場合もゲームは動作します。

| ファイル | 役割 |
| --- | --- |
| `src/engine.js` | DOMに依存しない対戦シミュレーションと単一の進行時計 |
| `src/analytics.js` | 公開URLのみで旧版と同じGoogle Analytics計測を初期化 |
| `src/app.js` | 画面遷移、入力、保存、HUD、パーティクル |
| `src/ui.js` | 札のDOMを維持し、配置・状態の差分だけを反映 |
| `src/audio.js` | ローカル音声・BGM・数字読み上げとイベントに応じた音量制御 |
| `src/card-label.js` | 分類名の語句分割、補足の表示、札内への文字サイズ調整 |
| `src/effects.js` | 必殺技の色・装飾・構図と、札から体力バーへの座標変換 |
| `src/config.js` | キャラクター、難易度、2人対戦キー配列 |
| `src/data.js` | 同梱NDC931件とバランス設定 |
| `src/story.js` | オープニングとエンディング本文 |
| `src/layout.js` | 縦横のステージ配置と元素材の縦画面版の対応 |
| `src/save.js` | セーブ読み込みと旧版からの一度だけの移行 |
| `styles.css` | 縦横の画面構成、演出、動きを減らす設定 |
| `scripts/create_special_se.py` | 旧SEの生成用（現在は使用せず、提供されたMP3を再生） |
| `scripts/build_offline.py` | 最新のソースからダブルクリック版を生成 |
| `scripts/check-assets.js` | 素材参照、分類データ、独立性の確認 |
| `scripts/source-assets.json` | コピー元素材のSHA-256一覧 |
| `tests/engine.test.js` | 対戦ルールと時間停止の自動検証 |

キャラクターアイコンはページ読み込みごとに新しいURLで取得するため、同名ファイルを差し替えた後は再読み込みで反映されます。通常の表情に加えて、正解時は `_icon_get.webp`、被ダメージ時は `_icon_damage.webp` を使用します。

編集後は `npm test` と `npm run check` を実行し、`python3 scripts/build_offline.py` でローカル版を更新します。`ndc.json` と `fighters_tuning.json` は元データの保管用で、実行時には `src/data.js` の同梱データを使用します。

## 公開について

GitHub Pages `https://yawatosho.github.io/karuta_heroes/` で公開する構成です。旧版のリポジトリ・Pages設定を維持して、新版のファイルへ置き換えます。`.nojekyll` と検証用GitHub Actionsを同梱しています。

Google Analyticsは旧版と同じ計測ID `G-J6NS8CCNWN`、ページ名 `NDC Karuta Heroes`、`game_mode: fighters` を使用し、ページ読み込みにつき1回の `page_view` を送信します。版を区別するパラメータは追加しません。URLのクエリ・ハッシュは計測URLから除きます。公開URLのルートと `index.html` だけで有効になり、localhost・オフライン版・previewではタグの読み込みも計測もしません。オフライン生成時は計測用スクリプトを除去します。設定画面の「アクセス解析について」から説明とGoogleの関連リンクを確認できます。

実際の受信は公開後、従来のGoogle Analyticsのリアルタイムレポートで確認してください。公開先を変更する場合は `src/analytics.js` の対象URLと `index.html` のOGP URLを合わせて変更します。
